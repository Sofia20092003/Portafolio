Este proyecto consiste en el desarrollo de un Currículum Vitae Web diseñado con HTML5 y CSS3, aplicando conceptos modernos de maquetación como Flexbox, Grid, animaciones suaves y diseño responsive.

Descripción:
Se trata de un CV digital estructurado en diferentes secciones:
 -Información personal
 -Formación académica
 -Experiencia laboral
 -Conocimientos técnicos (con barras de progreso animadas)
 -Habilidades e idiomas
 -Proyectos destacados
 -Formulario de contacto

El diseño está basado en un estilo limpio, minimalista y moderno, con tarjetas visuales, efectos hover y degradados.

Tecnologías utilizadas:
 -HTML
 -CSS:
   *Variables CSS (Custom Properties)
   *Flexbox
   *CSS Grid
   *Transiciones y animaciones
   *Pseudo-elementos (::before)
   *Diseño responsive sin media queries complejas

Características Destacadas:
🎯 Diseño centrado y estructurado en tarjetas
✨ Efectos hover con elevación (box-shadow + transform)
📊 Barras de habilidades animadas
📱 Adaptación automática mediante Grid (auto-fit y minmax)
🎨 Uso de degradados y sombras suaves
📩 Formulario de contacto estilizado

El proyecto incluye:
   *Perfil personal con imagen
   *Experiencia laboral en formato tarjeta
   *Sección de proyectos con enlaces a GitHub
   *Formulario funcional (estructura preparada para backend futuro)

Objetivo Académico:
Este proyecto fue desarrollado como práctica del ciclo formativo de Desarrollo de Aplicaciones Web (DAW), aplicando conocimientos de:
   *Maquetación web
   *Diseño responsive
   *Organización semántica en HTML
   *Buenas prácticas en CSS

Mejoras Futuras:
   *Añadir media queries específicas para móviles
   *Implementar validación del formulario con JavaScript
   *Conectar el formulario a un backend
   *Añadir animaciones más avanzadas
